# Demo walkthrough (3–5 minutes)

1. Run `start_windows.bat` and open `http://127.0.0.1:8000`.
2. Point out the synthetic-data banner and four database-backed overview counters.
3. Open Communities; search for AI Club and inspect verified skills. Add a test club if desired.
4. Open Unmet needs; create an open need with a required skill that a seeded club has verified.
5. Click Generate matches. Explain that candidates failing hard eligibility checks are excluded before scoring.
6. Open a recommendation and inspect its evidence IDs, component score breakdown, proposal, milestone, and unanswered coordinator questions.
7. Submit feedback, then accept for discussion or reject. Explain that acceptance records a proposal decision; it does not imply real clubs have consented.
8. Open Evaluation to see current persisted counts and graph node/edge totals. Run the smoke benchmark from the command line. Do not claim synthetic demo counts as real-world accuracy.
